# kialia — Stand beim Pausieren, 04.09.2026

Nutzbar für eine echte Reiseplanung. Was noch offen ist, steht unten und ist
nach Dringlichkeit sortiert.

## Der eine Blocker, den nur du lösen kannst

**SMTP fehlt.** Supabase verschickt keine Mails. Konkret heißt das:

- Ein **neuer** Mensch kann sich nicht registrieren — die Bestätigungsmail
  kommt nie an.
- **Passwort vergessen** funktioniert für niemanden.
- Ein Store-Review würde daran scheitern.

Für euch beide ist es folgenlos: eure Konten existieren, ihr bleibt angemeldet.

Der Weg: Brevo → Domain `kialia.app` autorisieren → **eigenen** SMTP-Key namens
`kialia` anlegen (nicht den von MealVibes wiederverwenden) → in Supabase unter
Auth → SMTP eintragen. Den Key bitte nicht in einen Chat schreiben, sondern
direkt in Supabase.

## Was jetzt gegen Datenverlust schützt

| | |
|---|---|
| Speicher voll oder blockiert | Warnung oben in der App statt stillem Verlust |
| iOS räumt nach 7 Tagen ab | dauerhafter Speicher wird beim Start erbeten |
| Sicherungsdatei | enthält jetzt auch die Fotos, Import schreibt sie zurück |
| kein Netz | Service Worker, Seiten network-first |
| Reise nur lokal | wird im Reise-Umschalter in Ocker benannt |
| Abgleich fehlgeschlagen | Banner, nicht mehr stumm |
| Reise löschen | Name muss getippt werden |

**Trotzdem:** lege vor der Pause einmal eine Sicherung an. Einstellungen →
„Alle Reisen sichern". Die Datei enthält alles, auch die Belege.

## Was offen bleibt

1. **Belege synchronisieren nicht zwischen Geräten.** Sie liegen in der
   IndexedDB des Geräts, auf dem sie aufgenommen wurden. Die Sicherungsdatei
   ist der Weg dazwischen. Richtige Lösung wäre ein Supabase-Storage-Bucket
   mit eigenen Regeln — ein eigenes Vorhaben, kein Nebenbei.

2. **Keine Umrechnungsansicht.** Die Rechenwährung ist eingestellt und Beträge
   werden umgerechnet angezeigt, aber es gibt keine Ansicht „alles in CHF".

3. **Formulare in den aufgeklappten Blättern** tragen noch die alten Abstände.
   Rein optisch, funktioniert.

4. **Sprachdiktat** hängt an einer Edge Function mit `gpt-4o-mini` und
   `whisper-1`. Läuft, ist aber nur an einem Gerät geprüft.

## Wie das Design gepflegt wird

Eine Quelle: der `:root`-Block in `src/styles.css`.

```bash
python3 scripts/sync_design_kit.py    # schreibt design/css/tokens.css + tokens.json
python3 scripts/generate_icons.py     # schreibt Logo, PWA-Größen, maskable, Favicon
```

Das Sync-Skript rechnet die Kontraste nach — Text gegen das Papier, Flächen
gegen die helle Schrift darauf — und warnt, wenn ein Ton unter 4,5:1 fällt. Es
hat dabei drei echte Fehler gefunden, die vorher unbemerkt waren.

## Prüfen und ausliefern

```bash
bun run typecheck && bunx eslint src && TZ=America/New_York bun test && bun run build
```

Deploy: `npx wrangler deploy`. Push auf `main` deployt **nicht** von selbst.

## Wenn der Service Worker je Ärger macht

In der Konsole auf kialia.app:

```js
navigator.serviceWorker.controller?.postMessage("kialia:sw-abschalten")
```

Danach neu laden. Er meldet sich ab und räumt alle Caches ab. Nötig sollte das
nicht sein — Seiten kommen network-first, ein Deploy gewinnt also immer.
